# Approved WattZap master templates

PROTECTED — changes to any file here require explicit approval from Naveen.
All templates share one chrome (`master-slide/master.mjs`): canvas gradient,
technical grid, glows, official header logo, safe margins, footer rule, footer
note and page marker. Templates only define the content zone. Never add a
template or vary the chrome per-slide.

| Template | Use for |
|---|---|
| `title-slide` | Deck opener / section divider |
| `three-column-overview` | Executive overview |
| `four-card-requirements` | Requirements / scope (2×2 cards) |
| `process-flow` | Customer journey / process (3–6 steps) |
| `architecture` | Hardware / data architecture (stacked layers) |
| `timeline` | Roadmap (3–6 milestones on a gradient rail) |
| `business-case` | Economics / quantified value (metric tiles + bullets) |
| `comparison` | Options / products side by side (2–3 columns) |

Content contract: `brand/schemas/slide-content.schema.json`. Working examples:
`brand/examples/vvdn-pilot/`.
